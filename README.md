# 🎡 Wheel Picker — A Truly Random Decision Wheel
A lightweight, fast, and secure random wheel for picking names, options, prizes, tasks, or anything else you can put on a wheel. Designed to be simple, reliable, and genuinely random.

👉 Try it here: https://randomfella.com

---

## ✨ Features

- **Truly random spins** using a cryptographically secure random number generator  
- **Unlimited entries** — add as many items as you need  
- **Customisable colours and wheel styles**  
- **Adjustable odds** for weighted choices  
- **Works on any device** (desktop, mobile, tablet, smartboard)  
- **No sign‑up required**  
- **Free to use**

---

## 🔢 How Randomness Works

The wheel uses the browser’s built‑in secure random generator:

- Powered by `window.crypto.getRandomValues()`
- Produces non‑predictable, non‑patterned results
- Ensures every entry has an equal chance unless weights are applied
- Prevents bias caused by animation timing or device performance

This makes the wheel suitable for fair decision‑making, games, raffles, and classroom use.
